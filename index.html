How to set up your free Firebase Cloud Database (2-minute guide)
  1. Go to console.firebase.google.com and click "Create a project" (Name it devusons-fleet).
  2. In the left sidebar, click Build > Firestore Database → Click "Create database" (choose closest region, e.g. asia-south1 (Mumbai)). Select Start in test mode.
  3. Go to Project Settings (gear icon) > General, scroll down to "Your apps" → click the Web icon (</>) → Register app.
  4. Copy the firebaseConfig = { ... } code and paste it into the box above, then click "Test & Save Cloud Connection"!
  5. Click "Push Local Fleet to Cloud" to instantly upload your 7 buses and 22 drivers to Firestore.
Recommended Firestore Security Rules: 
rules_version = '2';
service cloud.firestore {
  match /databases/{database}/documents {
    match /{document=**} {
      allow read, write: if true;
    }
  }
}
